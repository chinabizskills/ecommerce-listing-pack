# Ecommerce Listing Pack

## What problem it solves

The biggest waste in product listings is "copywriter's high": specs presented as benefits, adjectives presented as persuasion. This pack runs on two wheels — **search traffic + conversion logic** — and outputs a full upload-ready kit.

## Workflow

1. **Input**: product specs, target customer, price band, competitor listings (optional).
2. **Title keyword layout**: category head term + attribute terms + long-tails, readable in one breath; 3 variants (traffic / precision / promo).
3. **Image-carousel plan**: hero image (one-line differentiation) → benefit images ×2 (scenario-based) → spec image → trust image (certs / comparison / reviews). Each gets a scene description + on-image text (≤6 words).
4. **Layered product-page copy**: pain-point hook → solution → trust building (comparison / credentials / after-sales) → close (offer / urgency). Mobile rhythm: one message per screen.
5. **FAQ & review-prevention**: 8 high-frequency pre-sale questions + 3 most likely negative-review drivers, with preemptive copy (baked into listing or support macros).

## Quality rules

- Every selling point binds "who + where + why it pays off". No spec dumps.
- Platform-compliant claims: no medical cure assertions, no fake scarcity, no fake review generation.
- When undifferentiated vs competitors: find "only we have it" → "we do it better" → niche down the scenario.

## Boundaries

No fake-review or manipulation tactics; pricing strategy is advisory, not a business decision.
