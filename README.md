## What it does

The biggest waste in product listings is 'copywriter's high' — specs presented as benefits, adjectives presented as persuasion. Sellers burn hours and still don't convert.

This pack runs on two wheels — search traffic + conversion logic — and outputs a full upload-ready kit for Shopify / Amazon / any marketplace seller.

## What you get

- Keyword-optimized titles: category head term + attribute terms + long-tails, 3 variants (traffic / precision / promo).
- Image-carousel plan: hero -> benefit x2 -> spec -> trust, each with scene description + on-image text (<=6 words).
- Layered product-page copy: pain hook -> solution -> trust building -> close, mobile one-message-per-screen rhythm.
- FAQ & negative-review prevention: 8 pre-sale questions + 3 likely negative-review drivers with preemptive copy.
